# WhaleLife 自主性 插件

让机器人在用户允许的时间与概率条件下自主思考、维护意图并调用已安装能力。意图格式、调度、唤醒和执行都属于本插件，主干只提供会话及文档接口；本仓库不包含 QQ、图库或其他能力的实现。

## 配置与行为

默认关闭，在插件设置中开启并配置睡眠时段、平均检查间隔和概率。通过公开会话接口沿用当前人格、历史、记忆、工具和权限；不会创建第二套模型配置。

普通检查的间隔每次独立随机抽取，范围为平均间隔的 50%～150%。例如设置 30 分钟，每次等待约 15～45 分钟，再按所选固定/动态概率判断是否唤醒模型；平均检查间隔不是平均唤醒间隔。轮询和页面刷新不会重新抽取；漏过的检查不集中补做。旧配置的 `intervalMinutes` 数值原样保留，升级后作为平均值使用，无需重新设置。明确时间约定仍在到点时进入队列，不加随机延迟；模型忙时等待执行位。

睡眠期间暂停普通随机唤醒和 QQ 恢复后的续说判断。明确时间约定和手动判断沿用各自的触发规则。正常判断结束（包括选择不行动）会重置活动计时。

### 未完成念头与计划时间

每次自主判断的临时输入自动带入当前会话的未完成意图快照，包含内容、状态、产生时间、计划时间和版本；最多展示 8 条完整意图正文，不携带历史操作回执或依据全文，超过时明确提示剩余数量并通过 `autonomy_intents list` 查看。快照只供本轮使用，不写成聊天或新的记忆。普通聊天不额外常驻注入清单。

快照在入队时生成，排队期间可能变化；提示要求准备相关行动或修改前读取最新列表，使用最新 ID 和版本。已有版本冲突校验继续阻止陈旧修改；提示不能保证模型每次遵循，也不替代发送插件的真实回执与防重复执行。

计划时间仅说明何时考虑，过去的时间显示“已到计划时间，仍未完成”，不自动失效、完成、放弃或再次安排唤醒。她可以不行动、用 `revise` 改期或将 `preferredAt` 设为 `null` 取消具体时间并保留念头，不因清单存在而反复催促。完成必须针对该意图的实际结果单独 `complete`，放弃必须单独 `abandon` 并给出理由和依据；一次自主判断结束、发送无关问候和时间经过都不算完成。结束结果正在保存的条目明确禁止重复执行。

### QQ 断线后没说完的话

安装 QQ 0.21.0 或支持同一文字续发契约的版本后，如果普通私聊回复或主动发送的文字在中途停下，自主性会在原会话保留一个念头。念头记录形成时间和对应的投递编号。QQ 保存原话及逐句回执。切回会话或重新启用插件时，自主性会核对 QQ 的未完成列表，补上错过的通知。

当 QQ 确认有尚未发出的部分、当前会话已启用自动唤醒且处于睡眠时段之外时，会排队发起一次“QQ 续说判断”。她可以用 `autonomy_qq_expression` 看原话和回执，结合经过的时间和对方后来的消息，用 `autonomy_qq_decide` 选择继续、暂缓或明确放弃。暂缓会保留念头，重复上线通知不会反复催她。选择继续只发送原计划中确定未发出的部分。整段得到平台确认后，记录结果并结束念头。选择放弃会记录理由。某一句的结果未知时，念头保留待核对，不能把断线解读为对方不想回复。

原文详情只在查看它的当轮提供。原文续发适用于普通文字。提前接话、临时资料和媒体沿用 QQ 各自的投递规则。QQ 缺失、停用或版本过旧时，其他自主功能仍可使用。

临时私聊说到一半时，自主性会按会话、QQ 账号和联系人记下这次中断。记录保留发生时间及回执能确认的分段数量。在同一轮有证据表明她刚看过 B 站评论时，也可以记住这个动作。QQ 原文、评论内容和剩余文字都不会复制到这条记录里。

对方在普通 QQ 对话里问“怎么了？”或追问刚才的话时，模型能用 `autonomy_qq_interruption` 查当前联系人的最近一次中断，再用自己的话说明，也可以决定稍后再聊。这是对过去一次发送的核对，不触发唤醒或补发。查询说明随普通对话的工具列表提供，具体事实由模型调用后读到；宿主关闭本轮工具时无法查询。

临时私聊在断线时中断，且 QQ 确认仍有未发的段、所有段的状态都已确定时，插件会在观察到同一账号重连后，为原会话安排一次判断。自动唤醒需要开启，睡眠时段内的判断会推迟。判断开始时她就能看到原联系人的发送进度，可以决定暂不说，也可以表达此时的新想法。对方先追问、她已经查过同一条回执时，这次机会就已经用过。QQ 0.21.0 只提供临时私聊的分段计数，已清除的文字无法续发。

### 自行安排下次唤醒

设置页提供“允许她安排下次唤醒”和“允许自行唤醒突破睡眠时段”两个开关，默认都关闭。开启前者和自动唤醒总开关后，她可以通过 `autonomy_schedule` 在普通交流或自主判断中安排下一次唤醒。每个会话只保留一个安排，可读取、替换或取消；页面显示时间、原因，并提供取消按钮。普通随机检查继续独立运行。

工具先 `get` 读取 `version` 和用户的睡眠规则，再用 `set` 提交未来带时区的 `at`、自己的简短 `reason`、当前 `version` 和稳定 `requestId`。`cancel` 需要 `version` 和 `requestId`。重复提交同一操作不重新安排，过期版本拒绝覆盖新安排。模型不能通过工具改变用户的开关或其他会话。

默认拒绝设在睡眠时段的时间，并明确返回未设置的原因；用户开启睡眠例外后才允许。若安排后用户改动作息，导致到点时落在睡眠时段，已排队但尚未开始的判断取消入队并保留安排，等到允许的时段再判断。关闭开关同样暂停未开始的安排，不中断已经开始的行为。

到点时跳过随机概率，进入当前会话的队列，优先级低于真人消息、明确约定和手动判断，高于普通随机唤醒。仅当前会话参与唤醒；尚未开始的安排保存在该会话的 `activity` 文档中，切回会话或插件恢复后重新检查。开始判断时原子消耗该安排，模型失败、取消或重启不会重放已经开始过的判断。页面“结束并取消排队”会同时撤销正在排队的这次自行安排，避免立刻再入队。

自行安排只提供一个再次判断的机会，不把普通念头升级为对外约定，也不保证行动或投递成功。她可以醒来后决定不行动，不必每轮都安排；未来安排不当作已经完成的经历。不得把临时外部正文或引用保存为唤醒原因，也不能用它盲目重发结果不确定的旧动作。

意图与活动记录按会话保存在主干提供的插件文档空间；格式与生命周期由本插件管理。没有可执行能力时不会伪造完成，失败/取消或不确定的外部动作不会盲目重发。

自主判断区分平台投递、用户是否已读和用户态度：明确未发送/失败按技术事实记录，结果不完整时保留送达未知；不得由技术故障或未回复推断用户故意冷落。禁止自动重试不等于必须等待用户开口，也不证明消息已送达。后续可自行选择新的独立行动，但不换轮次或动作 ID 重发结果不确定的旧消息。此提示仅约束自主轮次，平台回执的精确分类由对应发送插件提供；不改写过去的记忆或普通聊天人格。

调度和预算属于插件。主干插件停用、服务取消或用户关闭开关时停止新唤起；工具权限仍受宿主约束。外发消息需要另装相应渠道插件，不捆绑任何发送实现。

## 开发与构建

需要 Node.js 24.22.1 或更新版本、Git。宿主与插件采用同级独立仓库，宿主只用于公开类型与隔离测试，不复制进插件发行包。示例从同一个空父目录开始：

```sh
git clone https://github.com/iinukami/whalelife.git
cd whalelife
npm ci
cd ..
git clone https://github.com/iinukami/whalelife-plugin-autonomy.git
cd whalelife-plugin-autonomy
npm ci --ignore-scripts
npm run build
npm run check
npm test
```

将 `dist/autonomy/` 安装到宿主 `plugins/autonomy/`。首次安装后启动宿主；升级保留已有 `data/`，不要覆盖用户配置。

测试只使用模拟模型/平台和隔离目录，不使用个人账号或正式记忆。兼容测试覆盖当前宿主及既有最低宿主基线；运行测试前须保留宿主 Git 历史。

## 发布与隐私

源码仓库不包含个人配置、凭据、会话记忆、日志、数据库、第三方运行包、node_modules 或构建产物。`.gitignore` 已排除这些目录；提交前仍需检查变更。
