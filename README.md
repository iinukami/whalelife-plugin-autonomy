# WhaleLife 自主性 插件

让机器人在用户允许的时间与概率条件下自主思考、维护意图并调用已安装能力。意图格式、调度、唤醒和执行都属于本插件，主干只提供会话及文档接口；本仓库不包含 QQ、图库或其他能力的实现。

## 配置与行为

默认关闭，在插件设置中开启并配置睡眠时段、平均检查间隔和概率。通过公开会话接口沿用当前人格、历史、记忆、工具和权限；不会创建第二套模型配置。

普通检查的间隔每次独立随机抽取，范围为平均间隔的 50%～150%。例如设置 30 分钟，每次等待约 15～45 分钟，再按所选固定/动态概率判断是否唤醒模型；平均检查间隔不是平均唤醒间隔。轮询和页面刷新不会重新抽取；漏过的检查不集中补做。旧配置的 `intervalMinutes` 数值原样保留，升级后作为平均值使用，无需重新设置。明确时间约定仍在到点时进入队列，不加随机延迟；模型忙时等待执行位。

睡眠期间只暂停普通随机唤醒，明确时间约定和手动判断不受影响；没有睡眠规则就没有该限制。正常判断结束（包括选择不行动）继续重置活动计时，原有动态概率规则保持不变。

意图与活动记录按会话保存在主干提供的插件文档空间；格式与生命周期由本插件管理。没有可执行能力时不会伪造完成，失败/取消或不确定的外部动作不会盲目重发。

自主判断区分平台投递、用户是否已读和用户态度：明确未发送/失败按技术事实记录，结果不完整时保留送达未知；不得由技术故障或未回复推断用户故意冷落。禁止自动重试不等于必须等待用户开口，也不证明消息已送达。后续可自行选择新的独立行动，但不换轮次或动作 ID 重发结果不确定的旧消息。此提示仅约束自主轮次，平台回执的精确分类由对应发送插件提供；不改写过去的记忆或普通聊天人格。

调度和预算属于插件。主干插件停用、服务取消或用户关闭开关时停止新唤起；工具权限仍受宿主约束。外发消息需要另装相应渠道插件，不捆绑任何发送实现。

## 开发与构建

需要 Node.js 24.22.1 或更新版本、Git。宿主与插件采用同级独立仓库，宿主只用于公开类型与隔离测试，不复制进插件发行包。示例从同一个空父目录开始：

```sh
git clone https://github.com/iinukami/whalelife.git
cd whalelife
npm ci
cd ..
git clone https://github.com/iinukami/whalelife-plugin-autonomy.git
cd whalelife-plugin-autonomy
npm ci --ignore-scripts
npm run build
npm run check
npm test
```

将 `dist/autonomy/` 安装到宿主 `plugins/autonomy/`。首次安装后启动宿主；升级保留已有 `data/`，不要覆盖用户配置。

测试只使用模拟模型/平台和隔离目录，不使用个人账号或正式记忆。兼容测试覆盖当前宿主及既有最低宿主基线；运行测试前须保留宿主 Git 历史。
